# v3 test on lola (production host)

Date: 2026-11-16. Branch: `v3-diversity`. Host: lola (M1 Ultra, 64 GB, macOS 26.6, ffmpeg 8.1.2).

## Summary

The v3 pipeline runs end to end on lola, unattended, under launchd's exact environment. Quote variety and
accuracy improved sharply against the v2 history. Testing surfaced five bugs, all fixed and pushed:

- mflux was not found under launchd
- the 9B image model is gated
- FLUX drew literal photo and print borders
- quotes came from non-horror titles and included profanity
- FLUX added a fake painter's signature

Separately, **no video has been uploaded since July**: `token.json` is missing on lola.

## Bugs found and fixed

1. **mflux not found under launchd.** The command lives in `.venv/bin`, which isn't on PATH, so every
   image fell back to SDXL. It is now resolved beside `sys.executable` (`3e2570e`).
2. **Klein 9B gated.** The default is now `flux2-klein-4b` (`4b75cb7`).
3. **Literal borders.** Styles naming an object ("polaroid photograph", "movie poster", "antique
   engraving") made FLUX draw the physical print with a frame. Styles now describe the look instead. A
   re-check of all six packs rendered full-bleed (`b81f805`).
4. **Quote content.** *True Detective* and *Severance* (not horror) and an F-bomb from *The Descent* got
   through. Both prompts now require horror titles and no strong profanity, with a regex backstop. Scene
   prompts now also exclude corpses, hanged figures and self-harm imagery, after a *Roanoke* image showed
   hanging figures (`b81f805`).
5. **Fake signature** on painted styles. The prompt now excludes signatures and watermarks (`937462d`).
